# ai-starter

**Память проекта для [Claude Code](https://docs.claude.com/en/docs/claude-code/overview).**
Открываешь новую сессию в папке проекта — а Claude уже знает цель, где вы остановились и что делать дальше.

[English version → README.md](README.md)

---

## Зачем это

Claude Code — как очень умный помощник с амнезией:
- **Между сессиями он всё забывает.** Каждый раз приходится объяснять заново.
- **В длинной сессии он «сжимает» разговор** — заменяет его кратким пересказом, и детали теряются.
- **Шаг за шагом уплывает в сторону** от того, что вы хотели с самого начала.
- **На большом проекте** (много кода, книга) легко потратить весь лимит, просто читая файлы.

## Что делает ai-starter

| Проблема | Решение |
|---|---|
| Всё забывает | Цель, состояние и план лежат в обычных текстовых файлах в папке `ai/` и подгружаются сами при каждом старте |
| Теряет детали при сжатии | Если работа долго не сохранена, Claude не сможет закончить ответ без `/save`. Перед сжатием полная запись разговора сохраняется |
| Уплывает от цели | Файл цели Claude менять не может. К каждому твоему сообщению тихо добавляется строка «цель / веха / задача» |
| Тратит много токенов | Старт стоит ~3–6 тыс. токенов на любом размере проекта. Claude ищет через карту и каталог, а не читает всё подряд |
| Знания теряются | Отдельная база знаний по идее [Андрея Карпати](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): исходники в `raw/`, конспекты в `wiki/` |
| Коммитит сам | Claude запрещено делать `git add/commit/push`. Он предлагает текст коммита — коммитишь ты |

Подходит для **новых и уже существующих** проектов: программ (проверено на Spring Boot) и больших текстов, например книг. Шаблоны на **русском и английском**.

## Быстрый старт

```bash
# 1. Скачать (один раз)
git clone https://github.com/swittchen/ai-starter.git ~/tools/ai-starter
echo "alias ai-starter='bash ~/tools/ai-starter/install.sh'" >> ~/.bashrc && source ~/.bashrc

# 2. Поставить в проект (новый или существующий — твоё ничего не затрётся)
ai-starter ~/projects/moj-projekt --lang ru

# 3. Первая сессия
cd ~/projects/moj-projekt && git init     # если это ещё не git-проект
claude                                    # на вопрос «доверяешь этой папке?» — ответь ДА
/kickoff                                  # короткое интервью → цель, критерии, план
```
Потом «заморозь» цель: `mv ai/GOAL.draft.md ai/GOAL.md && chmod a-w ai/GOAL.md` — и сделай коммит.

## Каждый день

```
claude          → Claude сам говорит: цель / где мы / следующий шаг
(одна задача из ai/PLAN.md)
/save           → всё записано, Claude предлагает текст коммита
git commit      → это делаешь ты
/clear          → чистый лист, следующая задача
```
Одна задача за сессию — самый надёжный и самый дешёвый режим.

## Команды

| Команда | Когда |
|---|---|
| `/kickoff` | самая первая сессия проекта |
| `/save` | после задачи, перед большой задачей, в конце |
| `/breakdown` | разбить большой кусок на задачи по одной сессии |
| `/check` | проверить, выполнены ли критерии готовности |
| `/ingest ai/raw/файл` | превратить документ в страницы базы знаний |
| `/query вопрос` | ответ по базе знаний со ссылками |
| `/lint` | раз в неделю — уборка базы знаний |
| `/drift` | раз в несколько сессий — не ушли ли от цели |

## Требования

- Claude Code
- git и bash (Linux/macOS; на Windows — Git Bash или WSL)
- python 3 — только если в проекте уже есть свой `.claude/settings.json`
