1. Запусти `bash .claude/scripts/wiki-lint.sh` — механическая часть (каталог, битые ссылки, длинные страницы) проверяется скриптом, без чтения страниц.
2. Исправь то, что он нашёл.
3. Смысловая часть — экономно: прочитай только ai/wiki/index.md и по нему выбери пары страниц с похожими темами (кандидаты в дубли/противоречия), максимум 6 страниц за один /lint. Каждую страницу читай только раз.
4. Очевидное исправь, спорное перечисли мне. Допиши в ai/wiki/log.md: `## [ГГГГ-ММ-ДД] lint | <итог>`.
