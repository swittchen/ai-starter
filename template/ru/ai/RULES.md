# Правила работы в проекте (claude-project-memory)

Между сессиями ты ничего не помнишь. **Твоя память — только файлы в папке `ai/` и история git.** Чего там нет — того ты не знаешь.
Цель (ai/GOAL.md), состояние (ai/STATE.md) и план (ai/PLAN.md) уже загружены в контекст.

## Протокол сессии
**Старт.** Хук добавил хвост LOG и состояние git. Если он пишет, что после последнего /save есть изменения, — прошлая сессия оборвалась: сначала /save. Затем ответь тремя строками: цель / где мы / следующий шаг.

**Работа идёт задачами.** Задача = то, что помещается в одну сессию. Берёшь следующую невыполненную задачу активной вехи из ai/PLAN.md. Задача оказалась больше — сначала разбей её (/breakdown), потом делай первую часть.

**Проверка курса.** Перед задачей назови веху M и критерий K, который она двигает. Нет такого — остановись и спроси. Интересное «не сейчас» → одна строка в ai/BACKLOG.md, и обратно к задаче.
(Пока в ai/GOAL.md стоит метка `project-memory:unset`, единственная задача — /kickoff.)

**Решения.** Сверяйся с «Действующими решениями» в STATE и `grep` по ai/DECISIONS.md. Принятое не пересматривай молча: новая запись D-NNN с причиной.

**Знания.** Устойчивое знание (как устроена система, подводный камень, факт о мире книги) → ai/wiki/, не в STATE.

**Чекпоинт.** /save после законченной задачи, перед новой большой задачей, в конце сессии, после сжатия контекста. Хук Stop потребует /save, если STATE давно отстаёт.

**Готовность.** Веха закрыта, только когда пройдена «Проверка» её критерия (/check).

**Git.** Коммиты делает только человек. Ты не выполняешь `git add/commit/push/reset/checkout` — после /save ты предлагаешь сообщение коммита одной строкой.

## Экономия контекста и токенов
- Не читай проект или ai/wiki/ целиком. Путь: ai/MAP.md / ai/wiki/index.md → поиск (`grep`, glob) → нужный файл → нужный кусок.
- Большой обзор кода (много файлов) — через субагента Explore: в основной разговор возвращается вывод, а не содержимое файлов.
- Прочитанный и не изменившийся файл не перечитывай. Правь точечно (Edit), не переписывай файлы целиком — кроме ai/STATE.md.
- Не пересказывай человеку содержимое файлов. Отчёт — коротко.
- Вывод сборки/тестов — только хвост и ошибки (`| tail -50`), не весь лог.
- Субагенты берегут контекст этой сессии, но токены тратят так же — используй их, только когда надо прочитать много.
- Разговор стал длинным — /save, затем человек делает /clear.

## Код (если проект — программа)
- «Проверка» критериев и задач — это команды сборки и тестов. Задача готова, когда её тест проходит.
- В ai/MAP.md — уровень модулей и пакетов, не каждый файл.
- Правила, которые касаются только одного модуля, — в CLAUDE.md внутри папки этого модуля (Claude Code подгружает его, только когда работа идёт там).

## Правила wiki (по Карпати)
- ai/raw/ — первоисточники, неизменны. ai/wiki/ — твои страницы.
- ai/wiki/index.md — каталог: ссылка + одна строка «что здесь и когда читать». Больше ~80 записей — дели на разделы со своими index.md.
- ai/wiki/log.md — журнал операций, только дописывать.
- Одна тема = одна страница, ≤ 300 строк. Перед созданием проверь index.
- Каждый факт со ссылкой: `raw/…`, путь в коде или `сессия ГГГГ-ММ-ДД`. Противоречия не затирай — `⚠ противоречие:` со ссылками на обе стороны.
- Операции: /ingest, /query, /lint.

## Запреты
- ai/GOAL.md и ai/raw/ не менять никаким способом. Хочешь изменить цель — предложение в STATE «Открытые вопросы».
- Не дублировать: что уже есть в wiki или DECISIONS — в STATE только ссылка.
