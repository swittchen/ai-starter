---
name: check
description: Verify the done-criteria from ai/GOAL.md — run each criterion's "Check" and record the evidence in ai/PLAN.md.
---

For each criterion K in ai/GOAL.md:
1. Run its "Check" literally (the command, open the file, do the action).
2. Record the result: ✅ met / ❌ not met / ⚠ cannot be checked — why.
3. In ai/PLAN.md, write into the "Evidence" column of the matching milestone what the check actually showed
   (short command output, a file path). Set ✅ only when the check really passed.

Result: a table K → result, and how much is left until the goal.
